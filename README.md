# Julo

Julo-ն աշխատանքի, նախագծերի և առաջադրանքների կառավարման հարթակ է։ Repository-ն բաժանված է երկու անկախ հավելվածի։

## `desktop/`

Համակարգչային տարբերակ՝ Electron-ի հիմքով։ Այն պահպանում է ներկայիս Julo Desktop ֆունկցիոնալը և հին Planer տվյալների անվտանգ migration-ը։ Desktop տարբերակը այս փուլում ֆունկցիոնալորեն սառեցված է։

## `webapp/`

Julo-ի նոր վեբ հավելվածը՝ նախատեսված նախագծերի և թիմային աշխատանքի ուղղությամբ զարգացնելու համար՝ Trello/Monday դասի աշխատանքային տրամաբանությամբ։ Այն կառուցված է առանձին և չի ժառանգում Planer-ի legacy UI/code-ը։

Webapp-ը հիմա local-first է։ Հետագայում այստեղ կավելացվեն backend, հաշիվներ, թիմեր, permissions և cloud sync։

## Լեզու

Julo-ի user-facing հիմնական լեզուն հայերենն է։ Legacy անունները կարող են պահպանվել միայն տեխնիկական migration-ի այն հատվածներում, որտեղ դրանց փոփոխությունը կարող է կոտրել հին տվյալների ներմուծումը։
