# Julo Desktop

Julo-ի համակարգչային տարբերակը նախատեսված է Windows-ում անձնական առաջադրանքների, նախագծերի, ժամանակացույցի և ժամանակի հաշվառման համար։

## Գործարկում

```bash
npm install
npm start
```

## Ստուգումներ

```bash
npm run check
npm test
```

## Windows build

```bash
npm run build
```

Տվյալները պահվում են տեղային։ Ամպային համաժամանակեցման provider այս փուլում միացված չէ։ Հին Planer profile-ի migration-ը պահպանված է միայն նախկին տվյալները անվտանգ տեղափոխելու համար։
